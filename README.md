# Oluwamuyiwa Ajibodu — Developer Portfolio

Responsive static portfolio built with HTML, CSS, and JavaScript and published with GitHub Pages.

## Files
- `index.html` — portfolio sections and project descriptions
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and interactive behavior
- `Oluwamuyiwa_Ajibodu_Resume.pdf` — downloadable resume
- `Oluwamuyiwa_Ajibodu_Resume.docx` — editable resume

## Publish with GitHub Pages
1. Upload all five files to the root of the repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Open the published site link shown on the Pages settings screen.

Project descriptions distinguish coursework from practice concepts. The portfolio does not claim that proposed concepts are completed products.

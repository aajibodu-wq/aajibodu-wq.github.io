# Oluwamuyiwa Ajibodu — Developer Portfolio

Responsive static portfolio built with HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — portfolio content and project concepts
- `style.css` — responsive visual design and print styles
- `script.js` — mobile navigation, year, and print action
- `Oluwamuyiwa_Ajibodu_Resume.docx` — editable resume draft
- `Oluwamuyiwa_Ajibodu_Resume.pdf` — PDF resume draft

## Before submitting
- Verify that every skill listed reflects your actual experience.
- Some project entries are proposed concepts, not claims of completed client work. Update them after you build them.
- Verify that the Christ Embassy media responsibilities listed on your resume accurately describe your experience.
- Add a LinkedIn profile link if you have one, or remove that link.

## Publish on GitHub Pages
1. Create a public repository. For a personal site, `aajibodu-wq.github.io` is a suitable repository name.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for deployment and open the URL displayed in Pages settings.

This site is static and does not use WordPress or a backend.
